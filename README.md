# Focus on Yourself

一个关于自我成长、认知提升与人与 AI 协同的持续研究仓库。

## 当前研究主题：人与 AI 协同

本仓库尝试回答一个核心问题：

**如何组织人类与 AI 的认知能力，使双方共同构成的系统能够更好地探索、验证、创造，并持续提升人类自身的能力？**

### 当前基本观点

- 人类定义目标、价值和责任边界，但不垄断思考权。
- AI 可以在明确约束下自主探索，并提出人类未预料到的假设。
- 结果的可信度来自与任务相匹配的独立验证，而不是模型表达的自信程度。
- 协作成果需要回流为人类自己的知识、判断和可迁移能力。
- 协作模式应按任务动态选择，而不是把人机关系固定为指令与执行。

> 这里的六个研究问题、认知闭环和五种协作模式属于持续演进的研究框架，不是已经被普遍验证的行业标准。欢迎通过真实案例、对照实验和文献研究持续修正。
